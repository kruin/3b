# Telefoonweergave op desktop

Op desktop staat bij de tafel een knop **Mobiele test op desktop**. Bovenaan een cursus of inhoudsopgave staat **Telefoonweergave**. Ook User kan het voorbeeld openen.

Vanuit de cursus opent het voorbeeld dezelfde patrooncursus, les, stap en meetbasis. Bij Aankomsten op ZUID blijft bijvoorbeeld VIJF+2 geselecteerd. Vanuit de tafel opent de actuele tafel in telefoonformaat.

Wissel tussen **Staand** en **Liggend** en sluit met **×** om op de oorspronkelijke pagina verder te gaan. Het voorbeeld gebruikt een tijdelijke kopie in het geheugen. Metingen en instellingen van de oorspronkelijke tafel worden daardoor niet gewijzigd. Het voorbeeld draait als User; een private databaseverbinding wordt niet doorgegeven.

Dit is een browserweergave op telefoonformaat. Test daarnaast met de QR-link op de echte telefoon.
